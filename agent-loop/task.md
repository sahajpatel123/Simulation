# TheCee — Autonomous Improvement Mission

Make TheCee (a Python FastAPI backend that simulates how 10,000 AI consumers
respond to a startup idea) continuously better — one completed, tested,
pushed change per loop pass, forever.

- Read AGENTS.md at the repo root every pass and follow its rules.
- ADD passes: implement ONE new, genuinely valuable feature — a new founder
  insight, simulation accuracy/calibration improvement, performance,
  observability, API ergonomics, documentation, or test coverage.
- POLISH passes: improve the most recently added feature or the weakest
  existing area — fix bugs, harden edge cases, add tests, optimize, clarify.
- Every pass ends with tests passing and a commit pushed to origin/main.
- Never degrade the project: no broken builds, no secret leaks, no
  destructive changes to existing work. Push to main only — never open a PR.
